# Крестики-нолики

Небольшая браузерная игра для двух игроков на одном устройстве.

## Как запустить

Скачайте файлы проекта и откройте `index.html` в любом современном браузере. Установка программ и подключение к интернету не нужны.

## Как играть

Игроки по очереди нажимают на клетки поля. Крестики ходят первыми. Побеждает тот, кто первым соберёт три своих знака по горизонтали, вертикали или диагонали. Кнопка «Новый раунд» начинает следующий раунд, а «Сбросить счёт» обнуляет результаты.

## Файлы

- `index.html` — разметка страницы и игрового поля.
- `style.css` — оформление и адаптация для небольших экранов.
- `script.js` — правила игры, проверка победы и счёт.
