# Крестики-нолики

Браузерная игра: человек играет крестиками против робота, который выбирает оптимальные ходы.

## Как запустить

Скачайте файлы проекта и откройте `index.html` в любом современном браузере. Установка программ и подключение к интернету не нужны.

## Как играть

Нажимайте на клетки поля, чтобы поставить крестик. После каждого вашего хода робот отвечает ноликом. Он использует полный перебор ходов и не проигрывает: при идеальной игре с обеих сторон получается ничья. Если кто-то соберёт три знака по горизонтали, вертикали или диагонали, на экране появится победитель. Кнопка «Новый раунд» начинает следующий раунд, а «Сбросить счёт» обнуляет результаты.

## Файлы

- `index.html` — разметка страницы и игрового поля.
- `style.css` — оформление и адаптация для небольших экранов.
- `script.js` — правила игры, проверка победы и счёт.
